# 透明麻雀 開発プラン（アプリ化まで）

## ゴール

- タイトル: **透明麻雀**
- モード: **CPU対戦** / **オンライン対戦**（ルームコードを発行して共有 → 同じ卓で対戦）
- 見た目: スマホゲームらしいリッチな卓UI（緑の卓・中央の点数パネル・ガラス調の透明牌・大きな発声演出）。
  既存タイトルの画像・UI素材は使わず、すべてオリジナルの SVG / CSS で作る。
- 最終的に iOS / Android アプリとしてストア配信する。

## フェーズ3: オンライン基盤の本番化

現在は PeerJS の公開シグナリングサーバー + P2P（ホスト端末が権威）で、サーバー費ゼロで動く。
本番運用では以下に移行する。

1. **自前シグナリング** と **TURN サーバー**（モバイル回線・企業NAT越えのため。例: Cloudflare Calls / Twilio / coturn）
2. もしくは **サーバー権威型** に移行（Cloudflare Workers + Durable Objects / Firebase / Supabase Realtime など）
   - `src/engine` はDOM非依存なのでそのままサーバーで動かせる
   - ホスト離脱で卓が終わる問題、チート（ホスト改造）対策になる
3. アカウント（匿名ログイン → Apple/Google サインイン）、フレンド、ランキング／段位戦
4. 観戦モード（透明牌ルールと相性が良い）

## フェーズ4: アプリ化（iOS / Android）

**方針: Capacitor でラップする**（Web と同じコードで iOS/Android を出せる。今の Vite 構成をそのまま利用）

1. 準備
   - `npm i @capacitor/core @capacitor/cli @capacitor/ios @capacitor/android`
   - `npx cap init 透明麻雀 jp.example.transparentmahjong --web-dir dist`
   - `npx cap add ios` / `npx cap add android`
2. ネイティブ対応
   - 画面を横向き固定（`Info.plist` / `AndroidManifest.xml`）、ステータスバー非表示、ノッチの safe-area 対応
   - `@capacitor/haptics` で打牌・鳴きの振動、`@capacitor/share` で招待コード共有
   - ディープリンク（`transparentmahjong://room/ABC123` / Universal Links）でコードから直接参加
   - サウンドのプリロード、バックグラウンド復帰時の再接続
3. ストア準備
   - アイコン・スプラッシュ（`@capacitor/assets` で生成）、スクリーンショット、説明文
   - プライバシーポリシー（オンライン対戦で扱う情報: 表示名・接続情報）
   - 年齢区分: 麻雀は賭博要素なし（ゲーム内通貨なし）で申請
   - Apple Developer Program / Google Play Console 登録
4. 配信
   - TestFlight / Google Play 内部テストでβ版 → 正式リリース
5. 収益化（任意）: 広告（対局間インタースティシャル）またはスキン・キャラの買い切り
